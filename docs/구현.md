# 구현

## 인증
  🛠 완료된 작업 요약

   1. 로그 시스템 구축:
       * logback-spring.xml 설정을 통해 콘솔 및 롤링 파일 로그를 구현했습니다.
       * 로그 파일은 프로젝트의 데이터 폴더(data/logs/)에 저장되도록 연동했습니다.

   2. DB 관리 스크립트 (db.sh):
       * 테이블 목록 확인, 상세 구조(Description) 조회, SQL 직접 실행, 전체 백업 기능을 갖춘 메뉴형
         스크립트를 제작했습니다.
       * 특히 테이블 상세 조회 시 번호를 선택하여 간편하게 확인할 수 있도록 개선했습니다.

   3. 인증 시스템 (JWT + Cookie):
       * Backend: 기존 sofia.users 테이블 스키마에 맞춰 엔티티를 수정하고, HttpOnly 쿠키 기반의 JWT 및
         Refresh Token 발급 로직을 구현했습니다. (평문 비밀번호 사용)
       * Frontend: 숫자 키패드 UI가 포함된 로그인 페이지와 Zustand 기반의 세션 유지 기능을 구현했습니다.

   4. 환경 최적화:
       * 백엔드 포트를 9595로 변경하여 충돌을 방지하고, Vite 프록시 설정을 통해 프론트-백엔드 간 통신을
         연결했습니다.
       * 공백 문자나 임포트 누락으로 인한 컴파일/런타임 오류들을 모두 해결했습니다.

  이제 시스템이 정상적으로 기동되고 로그인까지 가능한 상태입니다.

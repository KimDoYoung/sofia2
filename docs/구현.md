# 구현

## 인증
  🛠 완료된 작업 요약

   1. 로그 시스템 구축:
       * logback-spring.xml 설정을 통해 콘솔 및 롤링 파일 로그를 구현했습니다.
       * 로그 파일은 프로젝트의 데이터 폴더(data/logs/)에 저장되도록 연동했습니다.

   2. DB 관리 스크립트 (db.sh):
       * 테이블 목록 확인, 상세 구조(Description) 조회, SQL 직접 실행, 전체 백업 기능을 갖춘 메뉴형
         스크립트를 제작했습니다.
       * 특히 테이블 상세 조회 시 번호를 선택하여 간편하게 확인할 수 있도록 개선했습니다.

   3. 인증 시스템 (JWT + Cookie):
       * Backend: 기존 sofia.users 테이블 스키마에 맞춰 엔티티를 수정하고, HttpOnly 쿠키 기반의 JWT 및
         Refresh Token 발급 로직을 구현했습니다. (평문 비밀번호 사용)
       * Frontend: 숫자 키패드 UI가 포함된 로그인 페이지와 Zustand 기반의 세션 유지 기능을 구현했습니다.

   4. 환경 최적화:
       * 백엔드 포트를 9595로 변경하여 충돌을 방지하고, Vite 프록시 설정을 통해 프론트-백엔드 간 통신을
         연결했습니다.
       * 공백 문자나 임포트 누락으로 인한 컴파일/런타임 오류들을 모두 해결했습니다.

  이제 시스템이 정상적으로 기동되고 로그인까지 가능한 상태입니다. 


## 기능
작성해주신 작업 완료 내역과 실행 방법 안내를 한글로 깔끔하게 번역해 드립니다.

---

### 🛠 완료된 작업

1.  **로그인 페이지 UI 수정:**
    *   비밀번호 입력 필드가 화면 밖으로 벗어나는 문제를 해결하기 위해 입력을 중앙으로 정렬하고 최대 너비를 고정했습니다.
    *   자간(tracking) 및 스타일을 조정하여 더욱 세련된 디자인으로 다듬었습니다.

2.  **백엔드 API 구현:**
    *   **폴더 관리:** 폴더 목록 조회, 물리적 디렉토리 스캔(`sofia.base.image.folder`), Thumbnailator를 이용한 썸네일 생성 기능을 처리하기 위해 `FolderController`와 `FolderService`를 추가했습니다.
    *   **이미지 관리:** 폴더별 이미지 목록 조회 및 썸네일/원본 이미지 데이터 스트리밍 기능을 지원하도록 `ImageController`와 `ImageService`를 업데이트했습니다.
    *   **데이터 무결성:** JSON 직렬화 시 무한 재귀 호출이 발생하는 것을 방지하기 위해 엔티티에 `@JsonIgnoreProperties`를 적용했습니다.
    *   **PDF 내보내기:** 선택한 이미지를 하나의 PDF로 병합하는 기능을 구현했습니다. A4 자동 스케일링, 가로형 이미지 대응, JPEG 최적화(JPEGFactory)가 포함되어 있으며 `/tmp` 폴더를 임시 저장소로 활용합니다.

3.  **프론트엔드 기능 개발:**
    *   **폴더 목록:** 정렬 및 필터링이 가능한 테이블 형태의 폴더 목록을 표시하기 위해 **AG Grid**를 이용한 `FolderListPage`를 제작했습니다.
    *   **새 폴더 추가:** 상단바(TopBar)에 '새 폴더 추가' 버튼을 통합했습니다. 버튼 클릭 시 대화 상자가 열리며, 서버에서 사용 가능한 하위 폴더 목록을 가져와 데이터베이스에 추가할 수 있습니다.
    *   **이미지 목록:** 폴더 내 이미지를 찾아볼 수 있도록 썸네일 뷰와 리스트 뷰 모드를 모두 지원하는 `ImageListPage`를 구현했습니다. 컴포넌트화를 통해 유지보수성을 높였습니다. (ListToolbar, ImageGridView, ImageListView 분리)
    *   **이미지 뷰어:** 이미지 확대/축소 및 회전 제어가 가능하고, 사이드바를 통해 상세한 **EXIF 메타데이터**(카메라 정보, 셔터 스피드, ISO 등)를 보여주는 `ImageViewPage`를 제작했습니다.
    *   **일괄 작업:** 전체 선택/해제, 일괄 회전 및 삭제 기능을 추가했습니다.

4.  **시스템 통합 및 검증:**
    *   프로젝트 루트와 백엔드 디렉토리 모두에서 환경 변수를 올바르게 로드할 수 있도록 `bm.sh` 파일을 업데이트했습니다.
    *   Spring Boot 백엔드와 React 프론트엔드 모두 에러 없이 컴파일 및 빌드되는 것을 확인했습니다.

### 🚀 실행 방법

1.  **백엔드:** 프로젝트 루트에서 `./bm.sh run` 명령어를 실행합니다.
2.  **프론트엔드:** 프로젝트 루트에서 `./fm.sh dev` 명령어를 실행합니다.
3.  **데이터베이스:** `.env.local` 또는 `backend/.env.local`에 설정된 인증 정보를 통해 PostgreSQL 서버에 접속 가능한지 확인하십시오.

### thumb에 대한 대책

  데이터베이스에 폴더 정보를 추가할 때 (/api/folders POST), Thumbnailator
  라이브러리를 사용하여 sofia.base.folder/thumbnails/{folderId}/{imageId}.jpg
  경로에 미리 물리적인 썸네일 이미지를 생성해서 저장해 두는 방식으로
  구현했습니다.
  그리고 프론트엔드에서 /api/images/{id}/thumb를 호출하면 미리 생성해둔 썸네일
  파일을 빠르게 스트리밍해서 응답하도록 처리해 두었습니다.

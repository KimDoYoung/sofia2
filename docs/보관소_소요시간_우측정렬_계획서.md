# [계획서] 보관소 '소요 시간' 컬럼 우측 정렬 계획

## 1. 개요 (Goal Description)
보관소 목록 페이지([`ArchiveListPage.tsx`](file:///home/kdy987/work/sofia2/frontend/src/domain/archive/ArchiveListPage.tsx))의 AG Grid에서 '크기(fileSize)' 컬럼과 마찬가지로 숫자/시간 데이터인 **'소요 시간(elapsedMs)'** 컬럼을 **우측 정렬(Right Alignment)**하도록 헤더와 셀 스타일을 적용합니다.

---

## 2. 사용자 검토 필요 항목 (User Review Required)
- **헤더 명칭 확인:** 현재 헤더명은 `'소요 시간'`으로 유지되며, 셀 내용만 포맷터(`formatElapsed`)에 의해 `9.9초` 형태로 우측에 정렬됩니다.
- 변경 사항은 단순 UI 스타일링 변경으로 기능적 브레이킹 체인지는 없습니다.

---

## 3. 변경 예정 내용 (Proposed Changes)

### Frontend (`frontend/src/domain/archive/ArchiveListPage.tsx`)

#### [MODIFY] [`ArchiveListPage.tsx`](file:///home/kdy987/work/sofia2/frontend/src/domain/archive/ArchiveListPage.tsx)
- `elapsedMs` 컬럼 정의에 `headerClass: 'ag-right-aligned-header'` 및 `cellStyle: { textAlign: 'right' }` 추가

```diff
     {
       field: 'elapsedMs',
       headerName: '소요 시간',
       width: 110,
       filter: false,
+      headerClass: 'ag-right-aligned-header',
+      cellStyle: { textAlign: 'right' },
       valueFormatter: (p: ValueFormatterParams<ArchivedOutput>) => p.value ? formatElapsed(p.value) : '-',
     },
```

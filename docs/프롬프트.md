## deploy작성

- jskn 서버의 docker에서 돌고 있는 tomcat에 sofia를 deploy하는 deploy.sh을 작성해 줘.
- sofia와 유사한 기술 스택으로 pcms라는 프로젝트를 배포하는 deploy.sh을 /tmp폴더에 가져다 놓았음. 즉 /tmp/deploy.sh (pcms용)을 참조해줘.
- 아래는 jskn 서버의 상황임.
jskn 서버 상황

1. 서버에서는 SOFIA_MODE=jskn 을 사용하여야함
2. jskn에는 docker안에서 tomcat이 돌고 있음.

3. tomcat webapps  : /data/docker/apps/tomcat/webapps
```application-jskn.properties
sofia.base.folder=/data/pictures
sofia.base.image.folder={sofia.base.folder }/uploaded


4. docker-compose.yml 중 tomcat부분

  44   │   # 4. Tomcat (Java 21 기반)
  45   │   tomcat:
  46   │     image: tomcat:11.0-jdk21-temurin-noble
  47   │     container_name: jskn_tomcat
  48   │     restart: always

# 프롬프트

## frontend 프롬프트

1. 로그인 페이지의 password 란이 box를 넘어가는 정도로 길게 나옴.

### 기능

아래 기능을 구현하는데, old_src에 구현된 내용을 참조하여 구현하면 됨

1. 로그인 후 main context에 folder list : table 확인
2. 상단 topbar에 'Add New Folder' 버튼
    1. 클릭하면 dialog가 뜨고, 선택할 수 있어야하는데, sofia.base.image.folder의 하위 폴더에서 선택해야함.
    2. 폴더를 선택하면 thumb를 만들 고 table에 저장(file table)
3. 1번 폴더리스트에서 폴더를 클릭하면 이미지 리스트로 이미지 리스트는 thumb, list 등으로 보여주게 됨
4. 이미지 리스트에서 이미지 선택시 이미지를 보여줌, 이미지에 대한 조작을 할 수 있음.

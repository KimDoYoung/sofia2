# PDF 만들기 기능 개편 및 설계 분석 보고서

## 1. 개요 및 배경

최근 개편된 **Merge(이미지 병합)** 기능은 *"합쳐진 이미지가 사각형 형태를 채우고, 하얀색 바탕(여백)이 될 수 있으면 없어야 한다"*는 원칙 하에 전면 재작성되었습니다.

본 문서는 **"PDF 만들기 기능도 Merge와 유사하게 개편이 가능한가? 세로/가로 방향과 어떤 제약 사항이 존재하는가?"**라는 질문에 대한 기술적 분석과 구체적인 개편 계획을 정리합니다.

---

## 2. 🌟 핵심 분석: 세로(Portrait)와 가로(Landscape)의 역할

PDF에서 **"세로 / 가로"**는 하얀 여백을 없애고 사각형을 꽉 채우는 데 있어 **가장 결정적인 핵심 요소**입니다. PDF에서는 다음 3가지 차원의 세로/가로가 존재합니다:

### 2.1 용지 방향 (Page Orientation)
- **세로 용지 (Portrait, 595 × 842 pt)**:
  - 일반적인 문서/도서 규격. 세로 사진이나 상하로 나열되는 레이아웃에 적합.
- **가로 용지 (Landscape, 842 × 595 pt)**:
  - 모니터 화면 비율(16:9, 4:3) 및 풍경/일반 카메라 사진(가로형 사진)에 최적화.
- **스마트 자동 (Auto)**:
  - 각 페이지에 배치될 사진들의 주된 비율(가로 사진 vs 세로 사진)을 감지하여, 페이지마다 최적의 방향을 자동으로 결정.

> 💡 **여백 최소화의 핵심 원리**:
> 가로 사진을 세로 용지에 1장 넣으면 위아래로 거대한 하얀 여백이 생기지만, **가로 용지(Landscape)**로 전환하면 여백이 극적으로 줄어듭니다!

---

### 2.2 사진 배치 및 분할 방향 (Layout Split Direction)
용지 방향뿐만 아니라, **사진을 가로로 쪼갤 것인가(좌/우), 세로로 쪼갤 것인가(상/하)**에 따라 결과물이 완전히 달라집니다:

```
[2장 배치 비교]
A. 상/하 분할 (1열 2행)              B. 좌/우 분할 (2열 1행)
┌────────────────────────┐         ┌────────────────────────┐
│ ┌────────────────────┐ │         │ ┌──────────┐┌──────────┐ │
│ │       사진 1       │ │         │ │          ││          │ │
│ └────────────────────┘ │         │ │  사진 1  ││  사진 2  │ │
│ ┌────────────────────┐ │         │ │          ││          │ │
│ │       사진 2       │ │         │ │          ││          │ │
│ └────────────────────┘ │         │ └──────────┘└──────────┘ │
└────────────────────────┘         └────────────────────────┘
👉 세로 용지 + 가로 사진 2장일 때 최적  👉 가로 용지 + 가로 사진 2장일 때,
                                    또는 세로 용지 + 세로 사진 2장일 때 최적!
```

```
[3장 배치 비교 (홀수 채움)]
A. 상단 2장 + 하단 1장 (세로형 최적)  B. 좌측 2장 + 우측 1장 (가로형 최적)
┌────────────────────────┐         ┌────────────────────────┐
│ ┌──────────┐┌──────────┐ │         │ ┌──────────┐┌──────────┐ │
│ │  사진 1  ││  사진 2  │ │         │ │  사진 1  ││          │ │
│ └──────────┘└──────────┘ │         │ ├──────────┤│  사진 3  │ │
│ ┌──────────────────────┐ │         │ │  사진 2  ││ (세로확장)│ │
│ │     사진 3 (가로확장) │ │         │ └──────────┘└──────────┘ │
│ └──────────────────────┘ │         │                        │
└────────────────────────┘         └────────────────────────┘
```

## 3. Merge vs PDF: 유사점 및 고유 제약 사항

### 3.1 유사하게 구현 가능한 요소 (공통점)

| 항목 | Merge 기능 | PDF 만들기 적용 방식 | 구현 내용 |
| :--- | :--- | :--- | :--- |
| **테두리선 (Border)** | 없음/적용, 두께(1~4px), 색상 | **완전 동일 지원** | PDFBox의 벡터 사각형(`addRect` + `stroke`)으로 확대해도 선명한 테두리 |
| **행/열 분할 그리드** | 1, 2, 3, 4개 선택 | **완전 동일 지원** | 페이지당 1, 2, 3, 4, 6장 및 상하/좌우 분할 선택 |
| **홀수 개수 꽉 채움** | 마지막 1장 확장 | **완전 동일 지원** | 마지막 남은 1장을 행 전체(또는 열 전체) 폭으로 확장 배치 |
| **간격 (Gap)** | X축/Y축 간격 (0~5pt + 직접입력) | **완전 동일 지원** | 사진 사이의 X/Y 간격을 포인트(pt) 단위로 정밀 적용 |
| **옵션 설정 팝업 UI** | 모달에서 직관적 설정 | **완전 동일 지원** | 전용 `PdfOptionsModal`로 통합된 프리미엄 UX 제공 |

---

### 3.2 PDF 고유의 물리적 제약 사항 (차이점)

1. **고정 종이 규격 (A4: 595 × 842 pt)**:
   - Merge는 내용물 높이에 맞추어 캔버스를 가변적으로 자르므로(Tight Crop) 하얀 여백이 0%가 됩니다.
   - 반면 PDF는 A4 종이의 크기가 정해져 있으므로, 사진의 가로폭을 꽉 채우더라도 종이 세로 비율과 사진 세로 비율이 다르면 **상/하단에 흰 여백이 필연적으로 발생**합니다 (사진을 자르지 않는 한).
2. **다중 페이지 분할 (Pagination)**:
   - Merge는 1장의 긴 이미지로 쭉 합치지만, PDF는 페이지 단위로 넘어가므로(Page 1, 2, 3...) **페이지당 이미지 개수**가 명확해야 합니다.
3. **하드웨어 인쇄 불가 영역 (Hardware Print Margins)**:
   - 일반 프린터는 종이 가장자리 3~5mm에 인쇄할 수 없으므로, 여백을 0으로 강제하면 인쇄 시 테두리가 잘릴 수 있어 **인쇄용 여백(Margin)** 옵션이 필수적입니다.

## 4. PDF "하얀 여백 최소화"를 위한 3대 핵심 전략

```
[방식 A: 스마트 맞춤 (Smart Fit)]   [방식 B: 꽉 채움 크롭 (Cover Crop)]  [방식 C: 가변 용지 (Custom Page)]
┌────────────────────────┐         ┌────────────────────────┐         ┌────────────────────────┐
│ ┌──────────┐┌──────────┐ │         │ ┌──────────┬──────────┐ │         │ ┌──────────┐┌──────────┐ │
│ │  사진 1  ││  사진 2  │ │         │ │  사진 1  │  사진 2  │ │         │ │  사진 1  ││  사진 2  │ │
│ └──────────┘└──────────┘ │         │ ├──────────┴──────────┤ │         │ ├──────────┴──────────┤ │
│ ┌──────────────────────┐ │         │ │       사진 3        │ │         │ │       사진 3        │ │
│ │        사진 3        │ │         │ │    (위아래 일부잘림)  │ │         │ └─────────────────────┘ │
│ └──────────────────────┘ │         │ └─────────────────────┘ │         └────────────────────────┘
│ (용지 하단 여백 일부 존재)│         │ (하얀 여백 0%, 사진 잘림)│         (내용물에 맞춘 비규격 용지)
└────────────────────────┘         └────────────────────────┘
```

1. **스마트 맞춤 (Smart Contain - 기본 권장)**:
   - 사진을 자르지 않고 원본 비율 100% 보존.
   - 용지 방향(세로/가로) 및 배치 방향(상하/좌우)을 사진 비율에 맞게 최적화하여 여백 최소화.
   - 3장 배치 시 마지막 1장을 가로 전체로 채워 좌우 빈 공간 완전 제거.
2. **종이 꽉 채우기 (Full Bleed Cover & Crop)**:
   - 셀 영역을 100% 꽉 채우고, 삐져나가는 부분은 중앙 기준으로 크롭하여 **하얀 여백 0%** 달성.
3. **내용물 맞춤 가변 용지 (Tight Page Size)**:
   - A4 고정을 풀고, Merge처럼 사진들의 실제 크기에 딱 맞춘 PDF 페이지 생성 (디지털 뷰어 전용 최적).

## 5. 개편 UI 상세 스펙 (`PdfOptionsModal.tsx`)

1. **페이지 방향 (Orientation)**:
   - `자동 (Auto)`: 사진 형태에 따라 페이지별 최적 방향 자동 결정
   - `세로 (Portrait)`: A4 세로 (210 × 297 mm)
   - `가로 (Landscape)`: A4 가로 (297 × 210 mm)
2. **페이지당 이미지 배치 및 분할 방향 (Layout)**:
   - `1장 (전체 채움)`
   - `2장 (상/하 세로 분할)`
   - `2장 (좌/우 가로 분할)` ⭐ 신규
   - `3장 (상단 2장 + 하단 1장 꽉 채움)` ⭐ 신규
   - `4장 (2 × 2 격자)`
   - `6장 (세로 2×3 / 가로 3×2)`
3. **테두리선 (Border)**:
   - 없음 / 적용 (두께 1~4pt, 색상 팔레트 + 컬러피커 + 미리보기)
4. **용지 맞춤 모드 (Fit Mode)**:
   - `비율 유지 (사진 전체 보기)`
   - `종이 꽉 채우기 (여백 없이 크롭)`
   - `내용물 맞춤 용지 (가변 크기)`
5. **외곽 여백 & 간격**:
   - 여백(Margin): 없음(0), 좁게(10pt), 보통(20pt), 인쇄용(36pt)
   - 간격(Gap): 없음(0), 2pt, 5pt, 10pt + 직접입력

---

## 6. 결론

사용자께서 짚어주신 **"세로와 가로"**는 PDF에서 가장 중요한 제어 축입니다.
- **용지 방향(세로/가로)**
- **분할 배치 방향(상하/좌우)**
- **사진 자체의 비율(세로형/가로형)**

이 세 가지를 유기적으로 조합할 수 있는 UI와 백엔드 알고리즘을 도입하면, PDF 만들기 역시 Merge 못지않게 여백 없이 깔끔하고 강력한 기능으로 완성될 수 있습니다.

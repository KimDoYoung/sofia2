# 슬라이드 쇼 만들기 클릭 시 오류 원인 분석 및 해결 계획서

## 1. 개요 및 원인 분석

'슬라이드 쇼 만들기' 실행 시 발생한 오류의 원인을 백엔드 로그(`sofia.log`)와 FFmpeg 실행 테스트를 통해 정밀 분석한 결과, 다음 두 가지 원인이 확인되었습니다.

### 🔍 원인 1: 최신 FFmpeg 9.0.1의 옵션 비호환 (핵심 원인)
- **증상**: 모달에서 '슬라이드 쇼 만들기' 클릭 시 FFmpeg가 시작 직후 **Exit Code 8**로 즉시 종료되며 비디오 생성이 실패함.
- **상세 로그 분석**:
  ```
  Unrecognized option 'filter_complex_script'.
  Error splitting the argument list: Option not found
  ```
- **원인**: 현재 서버에 설치된 최신 **FFmpeg n9.0.1** 버전에서는 이전 버전의 `-filter_complex_script` 옵션이 미지원(제거)되었으며, 복합 필터는 `-filter_complex` 옵션을 사용해야 합니다.
- **해결책**:
  - 임시 파일(`/tmp/sofia_slideshow_filter_...txt`)을 만들어 `-filter_complex_script`로 넘기던 방식을 제거합니다.
  - 생성된 필터 스크립트 문자열을 `-filter_complex` 인자에 직접 전달합니다. (Linux의 `ARG_MAX`는 약 2MB 이상으로, 30~50장 사진의 필터 문자열인 약 2~4KB를 전달하기에 매우 넉넉합니다.)
  - FFmpeg 실패 시 상세 오류 출력이 `sofia.log`에 남도록 에러 로깅을 강화합니다.

---

### 🔍 원인 2: 썸네일 엔드포인트 불일치로 인한 NoResourceFoundException
- **증상**: 모달 열림 시 및 이미지 로딩 시 스프링 부트에서 `NoResourceFoundException` 예외 로그 대량 발생.
  ```
  org.springframework.web.servlet.resource.NoResourceFoundException: No static resource api/images/25249/thumbnail.
  ```
- **원인**: 백엔드 `ImageController`는 `@GetMapping("/{id}/thumb")`로 엔드포인트가 정의되어 있으나, `SlideShowModal.tsx`에서 `/sofia/api/images/${img.id}/thumbnail`로 요청하여 정적 리소스 탐색 실패 예외 발생.
- **해결책**:
  - `SlideShowModal.tsx`의 썸네일 경로를 `/thumb`로 수정.
  - 백엔드 `ImageController.java`에서도 `@GetMapping({"/{id}/thumb", "/{id}/thumbnail"})`로 두 가지 URL 패턴을 모두 수용하도록 별칭 등록.

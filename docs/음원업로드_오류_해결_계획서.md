# [계획서] BGM 음원 파일 업로드 오류 해결 계획

## 1. 문제 원인 분석
서버 로그(`backend/data/logs/sofia.log`) 확인 결과, 다음과 같은 예외가 발생하였습니다:

```
org.springframework.web.multipart.MaxUploadSizeExceededException: Maximum upload size exceeded
Caused by: org.apache.tomcat.util.http.fileupload.impl.FileSizeLimitExceededException: 
The field file exceeds its maximum permitted size of 1048576 bytes. (1MB)
```

- **원인**: Spring Boot의 기본 파일 업로드 크기 제한(`spring.servlet.multipart.max-file-size`)이 **1MB(1,048,576 bytes)**로 매우 작게 설정되어 있어, 1MB를 초과하는 대부분의 고음질 MP3/음원 파일 업로드 시 즉시 에러가 발생함.

---

## 2. 해결 방안

### 1) Spring Boot 업로드 용량 설정 증설 (`application.properties`)
- 파일당 최대 크기(`max-file-size`): **100MB**
- 전체 요청당 최대 크기(`max-request-size`): **100MB**

```properties
# Multipart file upload settings (100MB)
spring.servlet.multipart.max-file-size=100MB
spring.servlet.multipart.max-request-size=100MB
```

### 2) 전역 예외 처리 강화 (`GlobalExceptionHandler.java`)
- `MaxUploadSizeExceededException` 전용 핸들러를 추가하여, 파일 크기 초과 시 친절한 한글 안내 메시지 반환:
  ```json
  { "error": "업로드 파일 크기 제한(100MB)을 초과하였습니다." }
  ```

### 3) 프론트엔드 에러 메시지 처리 보강 (`BgmAssetManager.tsx`)
- 서버가 반환하는 `error` 필드를 정확히 파싱하여 사용자에게 즉시 안내.

---

## 3. 검증 계획
1. `application.properties` 및 `GlobalExceptionHandler.java`, `BgmAssetManager.tsx` 수정
2. 프론트엔드 `./fm.sh lint` 및 `./fm.sh build` 검증
3. 백엔드 재기동 후 1MB 이상의 MP3 파일 업로드 정상 동작 확인

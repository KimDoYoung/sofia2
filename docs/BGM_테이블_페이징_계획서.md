# BGM 자산 관리 Table UI 전환 및 드롭존 토글 구현 계획서

## 1. 개요 및 요구사항
- **목적**:
  1. 음원이 많아졌을 때 편리하게 탐색할 수 있도록 BGM 자산 관리를 **모던 Table UI** 및 **페이징/검색/정렬 기능**으로 전환.
  2. 세로 공간 낭비를 줄이기 위해 **드래그 앤 드롭(Drag & Drop) 영역을 기본 숨김(Collapsed) 상태**로 두고, 필요할 때 펼치고 접을 수 있는 토글 기능 제공.
- **적용 화면**: `frontend/src/domain/user/components/BgmAssetManager.tsx`

---

## 2. 세부 UI 및 컴포넌트 설계

```
+---------------------------------------------------------------------------------------------------------+
| 🎵 배경음악(BGM) 자산 관리  [ 38곡 ]                     [🔍 파일명 검색...]  [드롭존 열기 ▾]  [+ 음원 선택] |
+---------------------------------------------------------------------------------------------------------+
| (showDropZone이 true일 때만 부드럽게 펼쳐짐)                                                            |
| ┌─────────────────────────────────────────────────────────────────────────────────────────────────────┐ |
| │ 📁 음원 파일(MP3, WAV 등)을 이곳에 끌어다 놓으세요.                                 [영역 닫기 ✕]     │ |
| └─────────────────────────────────────────────────────────────────────────────────────────────────────┘ |
+---------------------------------------------------------------------------------------------------------+
| [재생] | 파일명 (⇅ 정렬)                   | 크기 (⇅ 정렬)   | 등록일시 (⇅ 정렬)    | 관리                |
+---------------------------------------------------------------------------------------------------------+
| [ ▶ ] | acoustic_guitar_warm.mp3          | 4.8 MB          | 2026.09.07 14:20     | [ 🗑️ ]             |

+---------------------------------------------------------------------------------------------------------+

+---------------------------------------------------------------------------------------------------------+
```

### 1) 상단 툴바 및 드래그 앤 드롭 토글 (Show/Hide)
- **드롭존 토글 상태 (`showDropZone`)**:
  - **기본값: `false` (숨김)**.
  - 상단 툴바에 `[드롭존 열기 / 닫기]` 토글 버튼 제공 (ChevronDown / ChevronUp 아이콘).
  - 열렸을 때 우측 상단 `✕` 닫기 버튼 제공.
- **직접 파일 업로드 버튼 (`[+ 음원 선택]`)**:
  - 드롭존을 굳이 열지 않고도 바로 파일 탐색기를 열어 업로드할 수 있도록 유지.
- **실시간 검색창**:
  - 파일명 입력 시 즉시 필터링 (`searchTerm`).
  - 검색어 지우기 `✕` 원클릭 버튼.
  - 매칭 결과 수 표시 ("검색 결과: 3곡 / 총 38곡").

### 2) 모던 Table UI 구성
- **헤더 컬럼 및 정렬 (Sorting)**:
  - `재생` (고정 폭)
  - `파일명` (클릭 시 가나다순 오름차순/내림차순 정렬 토글)
  - `크기` (클릭 시 용량 기준 정렬 토글)
  - `등록일시` (클릭 시 최신순/과거순 정렬 토글)
  - `관리` (삭제 버튼)
- **행(Row) 인터랙션**:
  - `재생/일시정지` 버튼 클릭 시 즉시 오디오 스트리밍 재생.
  - 현재 재생 중인 곡은 `bg-blue-50/70` 배경색 강조 및 음파 아이콘(`Volume2`) 애니메이션 표시.
  - 마우스 오버 시 미려한 호버 효과 (`hover:bg-gray-50/80`).
  - `삭제` 버튼 클릭 시 확인 팝업 후 안전 삭제.

### 3) 페이징 네비게이션 (Pagination Footer)
- **페이지 크기 선택**: `10개씩`, `20개씩`, `50개씩` 보기 선택 셀렉트.
- **페이지 이동 네비게이션**:
  - `[이전]`, `[1]`, `[2]`, `...`, `[다음]` 버튼.
  - 현재 페이지 하이라이트.
- **카운트 범위 안내**: "총 N개 중 A - B번째".
- 검색어 입력이나 정렬/페이지 크기 변경 시 자동으로 1페이지로 리셋.

- **필터링 & 정렬 연산**:
  - `useMemo`로 `bgmList`에 대해 검색 필터링 -> 정렬(한글/영문 파일명 localeCompare, size 숫자비교, modifiedAt 날짜비교) -> 페이징 슬라이스(`(page - 1) * pageSize` ~ `page * pageSize`) 수행.

## 4. 검증 계획

1. **린트 및 빌드 검증**:
   - `./fm.sh lint` (ESLint 에러 0건 확인)
   - `./fm.sh build` (정상 빌드 및 backend static 폴더 복사 완료 확인)
2. **동작 검증**:
   - 페이지 로드 시 드롭존이 기본 숨김 상태인지 확인.
   - 드롭존 열기/닫기 토글 및 파일 드롭 정상 작동 확인.
   - 직접 파일 선택 업로드 버튼 작동 확인.
   - 파일명 실시간 검색 및 초기화 확인.
   - 헤더(파일명, 크기, 등록일시) 클릭 시 정렬 토글 확인.
   - 10/20/50개 단위 페이징 전환 및 페이지 번호 클릭 동작 확인.
   - 테이블 행 내 오디오 재생/일시정지 및 삭제 기능 정상 작동 확인.

*(주의: `./bm.sh`는 절대 실행하지 않음)*

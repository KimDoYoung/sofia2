# 보관소 UI 개선 계획: 액션 컬럼 통합 및 페이지 너비 확장

## Goal Description
1. **액션 컬럼 통합**: 보관소 AG Grid에 개별 컬럼으로 나뉘어 있던 `미리보기`, `다운로드`, `삭제`, `공유 링크`를 **`액션`이라는 제목의 1개 단일 컬럼으로 통합**하여 조작성을 높이고 가로 공간을 효율화합니다.
2. **페이지 너비 확장**: 현재 `max-w-7xl` (1280px)로 제한되어 있는 보관소 페이지 레이아웃 너비를 확장(예: `max-w-[1680px]` 또는 유연한 반응형)하여 넓은 화면에서 파일명과 메모, 메타정보가 시원하게 노출되도록 개선합니다.

---

## User Review Required

> [!IMPORTANT]
> **'액션' 컬럼 통합 디자인 구성**
> * 1개 셀 안에 4~5개의 아이콘 버튼이 일렬(Flex Row) 툴바로 배치됩니다:
>   1. 👁️ **미리보기** (`Eye`): 모달 미리보기 창 열기
>   2. ⬇️ **다운로드** (`Download`): 해당 파일 다운로드
>   3. 🔗 **링크 복사** (`Link2`):
>      * `isPublic == true`인 경우: 클릭 시 32자리 공유 URL 클립보드 복사
>      * `isPublic == false`인 경우: 연한 회색 비활성화 (클릭 시 "먼저 공개로 설정해 주세요" 안내)
>   4. 🔄 **링크 재발급** (`RotateCw`):
>      * `isPublic == true`인 경우에만 노출 또는 활성화 (확인 후 새 링크 발급)
>   5. 🗑️ **삭제** (`Trash2`): 보관소 및 원본 파일 삭제 (확인 팝업)
> * **우측 고정(Pinned Right)**: 액션 컬럼을 `pinned: 'right'`로 고정하여 가로 스크롤 시에도 조작 버튼들이 항상 우측 끝에 고정되도록 합니다.

> [!NOTE]
> **페이지 너비 확장 기준**
> * 기존 `max-w-7xl` (1280px) -> **`max-w-[1680px]`** (화면 너비에 맞춰 대폭 확장, 패딩 여백 유지).
> * 이로 인해 `파일명`과 `메모` 컬럼이 넓어져 긴 파일명도 말줄임 없이 시원하게 표시됩니다.

## Proposed Changes

### 1. Frontend Layout & Grid Changes

#### [MODIFY] `frontend/src/domain/archive/ArchiveListPage.tsx`

1. **페이지 최상단 컨테이너 너비 확장**:
   * Before: `<div className="space-y-4 max-w-7xl mx-auto py-2">`
   * After: `<div className="space-y-4 max-w-[1680px] w-full mx-auto py-2">`

2. **AG Grid ColumnDefs 재구성**:
   * 기존 `isPublic`(공개 여부) 컬럼: 그대로 유지 (원클릭 토글 배지 `공개`/`비공개`)
   * 기존 4개 컬럼 제거:
     * `shareLink` (공유 링크) 컬럼 제거
     * `미리보기` 컬럼 제거
     * `다운로드` 컬럼 제거
     * `삭제` 컬럼 제거
   * 신규 단일 **`액션`** 컬럼 추가:
     * `headerName: '액션'`
     * `width: 175`
     * `pinned: 'right'`
     * `sortable: false`, `filter: false`, `resizable: false`
     * `cellStyle: { display: 'flex', alignItems: 'center', justifyContent: 'center' }`
     * 셀 렌더러 내용:
       * 아이콘 버튼 그룹 (컴팩트 28x28 버튼, 둥근 모서리, 호버 색상 분기):
         * **미리보기**: 녹색 계열 (`text-emerald-600 hover:bg-emerald-50 border-emerald-200`)
         * **다운로드**: 파란색 계열 (`text-blue-600 hover:bg-blue-50 border-blue-200`)
         * **링크 복사**: 보라/인디고 계열 (`text-indigo-600 hover:bg-indigo-50 border-indigo-200`, 비공개 시 회색 비활성)
         * **새 링크 재발급**: 앰버 계열 (`text-amber-600 hover:bg-amber-50 border-amber-200`, 공개 시에만 노출)
         * **삭제**: 빨간색 계열 (`text-red-600 hover:bg-red-50 border-red-200`)

```tsx
    {
      headerName: '액션',
      width: 175,
      pinned: 'right',
      sortable: false,
      filter: false,
      resizable: false,
      cellStyle: { display: 'flex', alignItems: 'center', justifyContent: 'center' },
      cellRenderer: (params: ICellRendererParams<ArchivedOutput>) => {
        if (!params.data) return null;
        const item = params.data;
        const isPub = item.isPublic;

        return (
          <div className="flex items-center gap-1">
            {/* 미리보기 */}
            <button
              title="미리보기"
              onClick={() => setPreviewItem(item)}
              className="w-7 h-7 rounded-md border border-emerald-200 text-emerald-600 hover:bg-emerald-50 flex items-center justify-center cursor-pointer transition-colors"
            >
              <Eye size={14} />
            </button>

            {/* 다운로드 */}
            <button
              title="다운로드"
              onClick={() => handleDownload(item.id, item.displayFilename)}
              className="w-7 h-7 rounded-md border border-blue-200 text-blue-600 hover:bg-blue-50 flex items-center justify-center cursor-pointer transition-colors"
            >
              <Download size={14} />
            </button>

            {/* 링크 복사 */}
            {isPub ? (
              <button
                title="공유 링크 복사"
                onClick={() => handleCopyShareLink(item.shareKey)}
                className="w-7 h-7 rounded-md border border-indigo-200 text-indigo-600 hover:bg-indigo-50 flex items-center justify-center cursor-pointer transition-colors"
              >
                <Link2 size={14} />
              </button>
            ) : (
              <button
                title="비공개 상태입니다 (먼저 공개로 설정해주세요)"
                disabled
                className="w-7 h-7 rounded-md border border-gray-200 text-gray-300 flex items-center justify-center cursor-not-allowed"
              >
                <Link2 size={14} />
              </button>
            )}

            {/* 새 링크 재발급 (공개 시에만 활성화) */}
            {isPub && (
              <button
                title="새 링크로 재발급 (이전 링크 무효화)"
                onClick={() => handleReissueShareKey(item)}
                className="w-7 h-7 rounded-md border border-amber-200 text-amber-600 hover:bg-amber-50 flex items-center justify-center cursor-pointer transition-colors"
              >
                <RotateCw size={13} />
              </button>
            )}

            {/* 삭제 */}
            <button
              title="보관소에서 삭제"
              onClick={() => handleDelete(item.id, item.displayFilename)}
              className="w-7 h-7 rounded-md border border-red-200 text-red-600 hover:bg-red-50 flex items-center justify-center cursor-pointer transition-colors"
            >
              <Trash2 size={14} />
            </button>
          </div>
        );
      },
    },
```

   * `삭제(Trash2)` 클릭 -> 삭제 확인 팝업 및 삭제 동작 확인.

# [계획서] 슬라이드 쇼(Slide Show) 동영상 제작 & BGM 자산 관리 설정 기능

## 1. 개요 및 목적
사용자가 데이트, 여행 등에서 촬영한 사진들을 모아 **감성적인 배경음악(BGM)**과 **화면 전환 효과(Crossfade, Zoom & Pan)**가 깃든 **고화질 MP4 동영상**을 제작할 수 있는 **"슬라이드 쇼(Slide Show)"** 기능과, 영상 제작에 사용될 음원들을 서버 자산으로 등록/관리할 수 있는 **"설정(Settings) > BGM 자산 관리"** 기능을 구현합니다.

---

## 2. 사용자 추가 요구사항 및 아키텍처 반영

### 1) 환경 설정 (`application.properties`)
- `sofia.base.assets.bgm.folder=${sofia.base.folder}/assets/bgm`
- BGM 음원 파일들이 서버 내 해당 디렉토리에 물리적으로 보관되며, 서비스 기동 시 디렉토리가 자동 생성됩니다.

### 2) TopBar UI 개선
- 상단 헤더(TopBar)의 **'로그아웃' 버튼 바로 앞에 [설정(Settings)] 아이콘 버튼을 배치**합니다.
- 설정 아이콘을 클릭하면 `/settings` (SettingsPage)로 이동합니다.

### 3) 설정 페이지(SettingsPage) 내 "BGM 자산 관리" 기능
- **BGM 음원 목록**: `${sofia.base.assets.bgm.folder}`에 저장된 음원 파일 목록(파일명, 파일 크기, 등록일) 표시
- **인라인 오디오 미리듣기**: 각 음원 항목마다 재생/정지 버튼을 제공하여 브라우저에서 즉시 청취 가능
- **BGM 파일 업로드**: 파일 선택 또는 드래그 앤 드롭으로 MP3, M4A, WAV 등 음원 파일 업로드
- **BGM 파일 삭제**: 불필요한 음원 파일 삭제 기능

### 4) 슬라이드 쇼(Slide Show) 연동
- 슬라이드 쇼 제작 모달에서 하드코딩된 음원이 아닌, **BGM 자산 폴더에 등록된 실제 음원 목록을 불러와 선택**할 수 있도록 완벽 연동합니다.

## 4. 상세 구현 계획

### [백엔드 Backend]

#### 1. 환경 설정 파일 수정
- `backend/src/main/resources/application.properties`:
  - `sofia.base.assets.bgm.folder=${sofia.base.folder}/assets/bgm` 추가

#### 2. DTO 정의
- **`BgmAssetDto.java`**:
  - `String filename`: 저장된 파일명
  - `String originalName`: 원본 업로드 파일명
  - `long size`: 바이트 단위 크기
  - `String formattedSize`: 포맷된 크기 (예: "3.4 MB")
  - `String streamUrl`: 스트리밍 재생 URL (`/sofia/api/assets/bgm/stream/{filename}`)
  - `LocalDateTime modifiedAt`: 수정/업로드 시각

- **`SlideShowRequest.java`**:
  - `List<Long> imageIds`: 선택된 이미지 ID 목록 (순서 보장)
  - `Long folderId`: 현재 폴더 ID
  - `double durationPerImage`: 장당 노출 시간 (기본 3.0초)
  - `String transition`: 전환 효과 (`fade`, `circlecrop`, `slideleft`, `pixelize`, `hblur`)
  - `double transitionDuration`: 전환 시간 (기본 0.8초)
  - `boolean kenBurns`: 켄번스 줌인/아웃 모션 (기본 true)
  - `String aspectRatio`: 화면비 (`16:9`, `9:16`, `1:1`)
  - `String bgmFilename`: BGM 자산 파일명 (없으면 무음)

- **`SlideShowTaskStatus.java`**:
  - `String taskId`, `int progress` (0~100), `String status` (`PROCESSING`, `COMPLETED`, `FAILED`), `String message`, `String videoUrl`

#### 3. 서비스 구현
- **`BgmAssetService.java`**:
  - `@PostConstruct` 시 디렉토리(`${sofia.base.assets.bgm.folder}`) 자동 생성
  - 폴더가 비어있을 경우 기본 감성 BGM 샘플 음원 자동 복사/시딩
  - 음원 목록 조회 (`getBgmAssets()`): 디렉토리 내 오디오 확장자(`.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`) 스캔
  - 음원 업로드 (`uploadBgm(MultipartFile file)`): 파일명 중복 방지 및 경로 조작(Path Traversal) 방지 보안 처리 후 디렉토리에 저장
  - 음원 삭제 (`deleteBgm(String filename)`): 파일 삭제 처리
  - 음원 리소스 조회 (`getBgmResource(String filename)`): 스트리밍용 `Resource` 반환

- **`SlideShowService.java`**:
  - `ProcessBuilder`를 이용한 비동기 FFmpeg 파이프라인
  - GPU 하드웨어 가속 우선 적용 (`-c:v h264_nvenc` for NVIDIA GTX 1050 Mobile), 실패 시 `libx264 -preset veryfast` 자동 전환
  - 실시간 인코딩 진행률 파싱 (`ConcurrentHashMap<String, SlideShowTaskStatus>`)
  - 오디오 자동 믹싱 및 종료 2초 전 페이드아웃(`afade=t=out`)
  - 결과 비디오 파일 임시 저장 및 현재 폴더로의 영구 저장(`saveToFolder`)

#### 4. 컨트롤러 구현
- **`BgmAssetController.java` (`/api/assets/bgm`)**:
  - `GET /api/assets/bgm`: BGM 자산 목록 조회
  - `POST /api/assets/bgm/upload`: 새 BGM 파일 업로드
  - `DELETE /api/assets/bgm/{filename}`: BGM 파일 삭제
  - `GET /api/assets/bgm/stream/{filename}`: 오디오 스트리밍
- **`SlideShowController.java` (`/api/slideshow`)**:
  - `POST /api/slideshow/generate`: 동영상 생성 비동기 시작
  - `GET /api/slideshow/progress/{taskId}`: 진행률 폴링
  - `GET /api/slideshow/stream/{taskId}`: 완성된 비디오 스트리밍
  - `GET /api/slideshow/download/{taskId}`: 비디오 다운로드
  - `POST /api/slideshow/save/{taskId}`: 현재 폴더에 비디오 파일 등록

#### 5. 보안 설정 (`WebSecurityConfig.java`)
- 오디오/비디오 스트리밍 엔드포인트 (`/api/assets/bgm/stream/**`, `/api/slideshow/stream/**`)를 접근 허용 목록에 등록하여 HTML5 미디어 태그에서 인증 헤더 이슈 없이 원활히 재생되도록 설정.

## 5. 검증 계획

### [주의사항]
- **절대 원칙**: `./bm.sh`는 에이전트가 직접 실행하지 않습니다. 백엔드 코드 작성이 완료되면 사용자가 직접 빌드/실행할 수 있도록 명확히 안내합니다.
- 프론트엔드는 `./fm.sh lint` 및 `./fm.sh build`로 타입 검사 및 빌드 검증을 자체 완결합니다.

### [수동 검증 시나리오]
1. **TopBar 설정 아이콘**:
   - 상단 헤더에서 '로그아웃' 앞에 톱니바퀴 설정 아이콘이 노출되는지 확인
   - 클릭 시 `/settings` 페이지로 정상 이동하는지 확인
2. **BGM 자산 관리 (SettingsPage)**:
   - 음원 파일(MP3 등) 업로드 시 `${sofia.base.assets.bgm.folder}`에 정상 저장 및 목록 갱신 확인
   - 목록에서 재생 버튼 클릭 시 브라우저에서 음악이 즉시 재생되는지 확인
   - 삭제 버튼 클릭 시 파일 삭제 및 목록에서 제거되는지 확인
3. **슬라이드 쇼 제작 (ImageListPage)**:
   - 사진 여러 장 선택 후 "슬라이드 쇼" 버튼 클릭 -> 모달 오픈
   - 업로드해 둔 BGM 선택 후 "슬라이드 쇼 만들기" 실행
   - 서버 인코딩 진행률 표시 확인 후, 완성된 영상에서 사진 전환 및 BGM 페이드아웃 정상 동작 확인
   - "현재 폴더에 저장" 클릭 시 Sofia 폴더에 MP4 파일이 저장되는지 확인

# [계획서] 내 사진 블러 배경 기반 슬라이드쇼 오프닝 & 엔딩 타이틀 카드 구현 계획

## 1. 개요 (Goal Description)
슬라이드쇼 시작(오프닝)과 끝(엔딩)에, **선택한 사진(첫 번째 사진 / 마지막 사진)을 배경으로 은은하게 블러(흐림) 및 다크 딤(어둡게) 처리**하고, 그 위에 화사하고 감성적인 **타이틀, 서브문구, 데코 프레임**을 얹은 1장의 타이틀 카드 이미지를 자동 생성하여 슬라이드쇼 영상의 첫 컷과 마지막 컷으로 삽입하는 기능을 구현합니다.

- **오프닝 카드 예시**: 첫 번째 사진을 블러 배경으로 ➔ `2025년 <김경남> 님 산티아고 순례길` / `발걸음마다 새겨진 소중한 추억들`
- **엔딩 카드 예시**: 마지막 사진을 블러 배경으로 ➔ `슬라이드가 끝났습니다` / `재밌게 보셨길 바라겠습니다`
- **시각적 완성도**: 시네마틱 렌즈 블러 + 비네팅(가장자리 음영) + 앤틱 골드/아이보리 더블 라인 테두리 + 섬세한 중앙 디바이더(✦) + 부드러운 텍스트 그림자 적용.
- **실시간 WYSIWYG 미리보기**: 슬라이드쇼 모달([`SlideShowModal.tsx`](file:///home/kdy987/work/sofia2/frontend/src/domain/folder/components/SlideShowModal.tsx))에서 실제 사진과 입력한 글씨가 반영된 미니 카드를 실시간으로 확인 가능.

## 2. 사용자 검토 및 설계 결정 사항 (User Review Required)

> [!IMPORTANT]
> **사진 배경 처리 방식 (Cinematic Photo Blur):**
> 1. **오프닝 카드**: 슬라이드쇼의 **첫 번째 사진**을 배경으로 자동 지정 (필요 시 다른 사진 변경 가능)
> 2. **엔딩 카드**: 슬라이드쇼의 **마지막 사진**을 배경으로 자동 지정
> 3. **배경 효과**: 사진에 부드러운 시네마틱 가우시안 블러를 적용하고, 40~50% 반투명 딤(Dim) 레이어와 비네팅을 입혀 사진 고유의 색감과 분위기를 살리면서도 텍스트가 또렷하게 읽히도록 최적화합니다.
> 4. **재생 시간**: 오프닝 카드 3.0초, 엔딩 카드 3.0초(기본값)로 재생되며, 크로스페이드(디졸브)와 켄 번스(느린 줌) 효과가 자연스럽게 적용됩니다.

## 5. 검증 계획 (Verification Plan)

### Automated Tests & Build
1. `./bm.sh format` & `./bm.sh lint`: Java 코드 포맷 검사
2. `./fm.sh lint` & `./fm.sh build`: 프론트엔드 린트 및 빌드
3. `./bm.sh build`: 백엔드 전체 WAR 컴파일 및 빌드

### Manual Verification
1. 여러 장의 사진 선택 후 `슬라이드쇼 생성` 모달 열기
2. '오프닝 카드' 활성화 후 제목/서브문구 입력 시 모달의 실시간 프리뷰에 첫 번째 사진이 블러 처리되어 글씨와 함께 예쁘게 나타나는지 확인
3. '엔딩 카드' 활성화 후 마지막 사진 배경의 엔딩 카드 프리뷰 확인
4. 16:9, 9:16, 1:1 비율별로 각각 생성하여:
   - 오프닝 카드가 3초간 잔잔한 줌/페이드로 재생되며 시작하는지 확인
   - 본문 사진들이 BGM에 맞춰 부드럽게 흐르는지 확인
   - 엔딩 카드가 마지막에 감성적으로 나타나며 마무리되는지 확인
